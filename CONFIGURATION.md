# Конфигурация

`.env` читается Docker Compose, имеет режим 0600, не попадает в Git или Docker build context. `configure.py` генерирует случайные пароли PostgreSQL и Redis, формирует URL с контейнерными DNS-именами и отказывается перезаписывать существующий файл.

| Параметр | Назначение |
|---|---|
| APP_HOST | DNS-имя Caddy, например ventilyator.company.local |
| APP_ORIGIN | Точный origin браузера, включая нестандартный порт; проверяется для CSRF |
| NODE_ENV | production требует HTTPS; development разрешён только в изолированной разработке |
| DATA_ROOT | Путь на хосте, по умолчанию /srv/ventilyator |
| POSTGRES_PASSWORD / REDIS_PASSWORD | Случайные локальные секреты; URL должны им соответствовать |
| DATABASE_URL / REDIS_URL | Серверные URL; никогда не передавать frontend |
| HTTP_PORT / HTTPS_PORT | Публикуемые порты Caddy |
| TLS_CERT / TLS_KEY | internal либо пути сертификата и ключа внутри контейнера |
| SESSION_MAX_DAYS | Абсолютный срок сессии, 7–90 дней, по умолчанию 30 |

## IMAP как дополнительная возможность

Параметры `IMAP_HOST`, `IMAP_PORT` (993), `IMAP_DOMAIN`, `IMAP_ORGANIZATION_ID` задаются только администратором на сервере. Реализован провайдер implicit TLS с проверкой сертификата; downgrade и пользовательский IMAP-host запрещены. Для корпоративного CA следует добавить доверенный CA в Node через `NODE_EXTRA_CA_CERTS` и отдельный read-only mount. Не отключайте `rejectUnauthorized`.

IMAP-вход допускается только для явно связанного `AuthIdentity(provider=imap, subject=email)` пользователя заданной организации. Автосвязывание по совпавшему email запрещено. Веб-управление настройками, безопасное связывание и auto-create ещё не реализованы; до их завершения IMAP не считается законченным пользовательским модулем. Локальные аккаунты остаются основным рабочим способом входа.

## Уведомления как дополнительная возможность

SMTP, BullMQ email-handler, центр уведомлений и настройки подписок запланированы на этап 5. Параметры SMTP сейчас не объявляются фиктивно работающими. Отключённые уведомления не должны блокировать приложение. Настроенные обязательные уведомления должны иметь явное состояние доставки и повторные попытки.

## Сеть при сборке

Требуются registry.npmjs.org, Docker Hub с его CDN и binaries.prisma.sh. Prisma проверяет контрольные суммы. Для браузерных тестов дополнительно нужен официальный CDN Playwright. После установки приложение не должно обращаться к этим адресам при обычной работе. В корпоративной среде поддерживается build secret `corporate_ca`; прокси задаётся стандартными Docker build args, доверие TLS сохраняется.
