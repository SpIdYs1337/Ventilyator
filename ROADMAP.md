# Выполнено и оставшаяся область работ

Полная область продукта сохраняется по [исходному заданию](docs/requirements.md). Этот выпуск расширяет рабочую платформу, но не завершает весь перечень Jira/Confluence и не является результатом production-аудита.

## Реализовано

- [x] Docker Compose, PostgreSQL, Redis, worker, локальные данные, Caddy HTTPS и отдельный LAN HTTP-профиль, автозапуск Docker.
- [x] Обязательные локальные аккаунты, создание через веб администратора, роли, блокировка/редактирование, сброс и смена пароля, серверные сессии, отзыв и аудит.
- [x] Дополнительный IMAP: веб-настройки/тест TLS, явное связывание, необязательное автосоздание с непривилегированной ролью.
- [x] Проекты, участники и серверные ACL, задачи, список/доска, фильтры, комментарии, история, optimistic locking.
- [x] Настраиваемые статусы и переходы, ограничения администратора и WIP, подзадачи, зависимости без циклов, чек-листы, наблюдатели, метки, оценки и story points.
- [x] Спринты: backlog, один активный спринт, закрытие со снимком результата и возвратом незавершённого в backlog; календарь, временная шкала, отчёты и реальный учёт времени/таймер.
- [x] База знаний: пространства и участники, дерево/архив, Tiptap, таблицы, защищённые изображения, оглавление, личные черновики, публикации, конфликты, версии и восстановление, комментарии, @упоминания и отметки чек-листов в режиме просмотра.
- [x] Markdown import/export, печать в PDF через браузер, связи страниц/задач и атомарное создание задачи из документа.
- [x] Вложения: потоковая загрузка, версии, SHA-256, безопасные пути, права скачивания, корзина/восстановление, квоты/резервирование, сверка незавершённых операций; опциональный ClamAV INSTREAM.
- [x] Рабочий стол с сохраняемыми виджетами, полнотекстовый поиск задач/страниц/проектов, центр уведомлений и настройки email.
- [x] SMTP TLS/STARTTLS, PostgreSQL outbox → BullMQ, повторные попытки, журнал доставок и проверка прав перед отправкой; уведомления о сроках.
- [x] Резервное копирование PostgreSQL + storage + ключ SMTP, manifest/SHA-256, восстановление только в пустую отдельную установку, скрипт обновления.
- [x] Собственный адаптивный дизайн, мобильная навигация, тёмная тема, отдельная загрузка редактора.

## Уточнения пользователя

Локальные пользователи обязательны и не зависят от почты. IMAP и уведомления реализованы как дополнительные опции; отсутствие SMTP/IMAP не блокирует проекты, документы и локальный вход. На клиентском компьютере не требуется установка Ventilyator.

Результаты выполненных проверок — [DEVELOPMENT.md](DEVELOPMENT.md). Завершённые пункты не означают полного соответствия всем деталям исходного задания.
